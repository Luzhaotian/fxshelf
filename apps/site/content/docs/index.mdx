**fxshelf** 是一组可复制源码、按需安装的 React / Vue 微动效包。

每个动效独立发布在 `@fxshelf/*` 下，只装你需要的那个即可。

  <Card title="Glyph Rain" href="/docs/effects/glyph-rain" description="Matrix 风格字符雨 —— 光标搅动，可选内容照明。" />
  <Card title="Starfield" href="/docs/effects/starfield" description="Canvas 星空隧道 —— 透视飞近、闪烁与拖尾。" />
  <Card title="Button Kit" href="/docs/effects/button-kit" description="按钮动效书架 —— 用 variant 字符串切换样式。" />
  <Card title="Word Tunnel" href="/docs/effects/word-tunnel" description="3D 词云隧道 —— 文字朝灭点飞来。" />
</Cards>

```bash
npm install @fxshelf/card-orbit
npm install @fxshelf/glyph-rain
npm install @fxshelf/starfield
npm install @fxshelf/button-kit
npm install @fxshelf/word-tunnel
```

已发布包见 [npm `@fxshelf`](https://www.npmjs.com/org/fxshelf)。CDN 示例与完整用法见各动效文档页。

## MCP

在 Claude Code、Cursor 等支持 MCP 的 AI 助手里接入 `@fxshelf/mcp`，助手即可直接发现动效、读取文档、获取可复制源码与锁定版本的 CDN 片段。本地 stdio 运行，**无需 API key、无需联网**。

写入 MCP 客户端配置（如 `~/.claude.json` 的 `mcpServers`，或 Cursor 的 `mcp.json`）：

```json
{
  "mcpServers": {
    "fxshelf": {
      "command": "npx",
      "args": ["-y", "@fxshelf/mcp"]
    }
  }
}
```

工具一览：

| 工具 | 返回内容 |
|------|----------|
| `ping` | 连通性检查：ok 标志、服务名/版本、动效数量、快照时间（可选回显） |
| `list_effects` | 全部动效：id、标题、简介、npm 包名、版本、文档链接 |
| `get_effect_docs` | 单个动效的完整文档 Markdown（安装、React/Vue 用法、API） |
| `get_effect_source` | 真实源码文件（`core` / `react` / `vue` 三组），带路径，可直接复制 |
| `get_cdn_snippet` | 锁定版本的 `<script>` 片段（unpkg / jsDelivr、可运行 HTML 示例） |

配置好后可以直接对助手说「给我的 hero 区加一个星空隧道背景」「把 word-tunnel 的 Vue 源码给我」，或先说「测试一下 fxshelf MCP 是否连通」验证接入。详见 [`@fxshelf/mcp`](https://github.com/Luzhaotian/fxshelf/tree/main/packages/mcp)。

## 新增动效

1. 在 `packages/<id>/` 新建包，`name` 设为 `@fxshelf/<id>`
2. 在 `apps/site/lib/effects.ts` 追加一条 registry
3. 添加 `apps/site/content/docs/effects/<id>.mdx`
4. 更新 `apps/site/content/docs/effects/meta.json`
5. 如需，更新根目录 `package.json` 脚本（`build` / `typecheck` / `pack:check` / `lint`）以及 `apps/site` 依赖
6. 首页卡片会自动读取 registry；文档页 Cards 请同步补上
