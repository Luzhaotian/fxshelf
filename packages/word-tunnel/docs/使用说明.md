# 使用说明

## 安装

```bash
npm install @fxshelf/word-tunnel
```

```ts
import '@fxshelf/word-tunnel/styles.css'
```

## React

```tsx
import { WordTunnel } from '@fxshelf/word-tunnel'
import '@fxshelf/word-tunnel/styles.css'

<WordTunnel style={{ height: 420, background: '#0c081e' }} />
```

## Vue

```vue
<script setup lang="ts">
import { WordTunnel } from '@fxshelf/word-tunnel/vue'
import '@fxshelf/word-tunnel/styles.css'
</script>

<template>
  <WordTunnel :style="{ height: '420px', background: '#0c081e' }" />
</template>
```

## Props

| 属性 | 说明 | 默认 |
|------|------|------|
| `words` | 词条数组 | 内置搞笑词 |
| `count` | 固定词数；不传则按宽度自适应 | — |
| `seed` | 随机种子（同值布局可复现，换值换分布） | `20250913` |
| `perspective` | CSS perspective | `900` |
| `innerRadius` | 中心空洞半径 | `8` |
| `outerRadius` | 外圈采样半径 | `52` |
| `travelMin` | z 最短飞行距离 | `480` |
| `travelRange` | z 额外随机飞行距离 | `560` |
| `fadeIn` / `fadeOut` | 淡入完成 / 开始淡出进度 0–100 | `10` / `88` |
| `color` / `fontSize` | 文字样式 | — |
| `children` / slot | 叠在词云上的内容 | — |
