# 动效说明（专业）

> 大白话版见 [动效说明-大白话.md](./动效说明-大白话.md)

Word Tunnel 用 CSS 3D（`perspective` + `translate3d` / `rotate`）做「朝灭点飞来」的词云隧道，无 Canvas / WebGL。

实现：`src/core/keywords.ts` · `src/core/styles.css` · `src/react/WordTunnel.tsx` · `src/vue/WordTunnel.vue`

## 管道总览

1. **采样**：在环外随机取 (x, y)，带最小间距拒绝，避免词叠在一起  
2. **深度**：每条词绑定一个 z 行程；动画只推进 z，透视自然汇向灭点  
3. **相位**：`animation-delay` 用负值错开，看起来一直在飞，而不是齐刷刷起步  
4. **内容**：默认 keyword 列表可换；字号 / 颜色 / 速度由 props 映射到 CSS 变量或 inline style

无 Framer Motion / GSAP。适合 Hero / 氛围背景；大量 DOM 节点时注意控制词数。
