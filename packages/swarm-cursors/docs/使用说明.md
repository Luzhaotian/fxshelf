# Swarm Cursors · 使用说明

```bash
npm install @fxshelf/swarm-cursors
```

```tsx
import { SwarmCursors, createDemoScene, createScene } from '@fxshelf/swarm-cursors'
import '@fxshelf/swarm-cursors/styles.css'
```

## 嵌入预览（推荐用于卡片）

```tsx
<div style={{ height: 420 }}>
  <SwarmCursors
    embed
    autoStart
    sceneFactory={createDemoScene}
    showDialog={false}
    showRulers={false}
    style={{ height: '100%' }}
  />
</div>
```

## 整页施工

```tsx
<SwarmCursors sceneFactory={createScene} />
```

点击 intro 或向下滚动后开始分配任务；滚动推进施工前沿。

## 主要 props

| Prop | 说明 |
|------|------|
| `sceneFactory` | `(getWorkerCount) => { els, tasks, groups, height }` |
| `embed` | 根节点作为滚动容器 |
| `autoStart` | 挂载后立刻开工 |
| `showOverlay` / `showRulers` / `showDialog` | 施工辅助 UI |
| `interactions` / `onAction` | 点击热区与自定义动作 |

更换场景请用 `key` 重新挂载。

## 字体

引擎会尝试加载 Space Grotesk / Source Sans 3 / IBM Plex Mono；超时后仍会启动。
