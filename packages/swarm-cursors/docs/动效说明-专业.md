# Swarm Cursors · 专业说明

## 架构

- `SwarmEngine`（继承 `DrawingEngine`）：任务依赖图、滚动前沿（frontier）、工人光标 flock / 分配 / 绘制生成器。
- `SceneBuilder`：声明式场景（path / rect / text / guide / duplicate / frame / logo）。
- React 层：`useSwarm` 驱动 rAF + 视口缩放；`SwarmExperience` 渲染画布、光标层、可选标尺 / overlay / dialog。

设计坐标系宽度固定 `PAGE_WIDTH = 1280`，窄屏等比缩放。

## 嵌入模式

`embed` 时滚动与尺寸取自根节点（`ResizeObserver` + `scrollTop`），指针坐标相对根节点换算，避免污染 window。
