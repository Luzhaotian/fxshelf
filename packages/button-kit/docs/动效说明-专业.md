# 动效说明（专业）

> 大白话版见 [动效说明-大白话.md](./动效说明-大白话.md)

Button Kit 是一组 **纯 CSS** 按钮变体：共享 `.fx-btn` 基类，按 `variant` 字符串挂载 `.fx-btn--*` 修饰符。React / Vue 封装只负责把 `variant` 映射到 class，不跑 JS 动画循环（除 CSS `@keyframes`）。

实现：`src/core/styles.css` · `src/core/variants.ts` · `src/react/Button.tsx` · `src/vue/Button.vue`

## 变体一览

| variant | 手法 |
|---------|------|
| `solid` / `outline` / `soft` | 静态填充 / 描边 / 浅底 |
| `chroma` | 默认渐变流光；hover 时 `::before`（`inset: -4px`）轻微 blur 贴边发光 |
| `liquid` | `::before` 自下升起，hover 后轻微波浪形变 |
| `wipe` | 斜向层从左擦入 |
| `glass` | 半透明 + `backdrop-filter` |
| `glow` | 无限 `box-shadow` 脉冲 |
| `shimmer` | `::before` 斜向高光平移 |
| `neon` | 描边 + 外发光 + 文字阴影 |

未知 `variant` 时回退到默认样式。无 Framer Motion / GSAP。
