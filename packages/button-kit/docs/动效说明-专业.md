# 动效说明（专业）

Button Kit 是一组纯 CSS 按钮变体：共享 `.fx-btn` 基类，按 `variant` 挂载 `.fx-btn--*` 修饰符。

- `chroma`：默认渐变流光；hover 时 `::before`（`inset: -4px`）以轻微 blur 贴边发光
- `liquid`：`::before` 自下而上升起，hover 后轻微波浪形变
- `wipe`：斜向层从左擦入
- `glass`：半透明 + `backdrop-filter`
- `glow`：无限 `box-shadow` 脉冲
- `shimmer`：`::before` 斜向高光平移
- `neon`：描边 + 外发光 + 文字阴影
- 其余为 hover / active 过渡

无 JS 动画循环（除 CSS `@keyframes`），无 Framer / GSAP。
